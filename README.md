# accord-watch

مراقبة يومية لإعلانات هوندا أكورد (Honda Accord) المستعملة في عمان، يديرها 9 وكلاء (subagents) في Claude Code. كل يوم يجمعون الإعلانات، يدققون النص والصور، يقارنونها، يستنتجون المعلومات غير المذكورة، ثم يحدّثون قائمة مرتبة في `reports/latest.html`.

## الفرق

| الفريق | الوكيل | المهمة | النموذج (model) |
|---|---|---|---|
| الجمع (Collection) | الكشّاف (scout) | يجمع الإعلانات من المواقع | sonnet |
| | الأرشيفي (archivist) | يحمّل الصور ويكشف الإعلانات المكررة والصور المعاد استخدامها | haiku |
| التدقيق (Inspection) | القارئ (text-auditor) | يستخرج البيانات من النص ويلتقط العبارات المبهمة | sonnet |
| | العين (visual-inspector) | يفحص الصور: الصبغ، الفراغات، الضرر، العداد، التجهيزات | opus |
| | المطابِق (cross-checker) | يقارن كلام الإعلان بالصور ويسجّل التعارضات | sonnet |
| الاستنتاج (Inference) | المحقق (inferencer) | يستنتج الجيل والمحرك والوارد ونمط الاستخدام وأسئلة للبائع | opus |
| | المثمّن (pricer) | يقارن السعر بمتوسط السوق | haiku |
| القرار (Decision) | الحَكَم (ranker) | يعطي درجة الحالة ويحدّث الترتيب | opus |
| | المحرر (reporter) | يكتب ملخص اليوم ويبني صفحة القائمة | sonnet |

## ما تحتاجه قبل البدء

- [Claude Code](https://claude.com/claude-code) مع اشتراك Claude (في الترمنال، أو إضافة VS Code، أو تطبيق Claude على الكمبيوتر).
- [Python](https://www.python.org/downloads/) 3.10 أو أحدث.
- [Node.js](https://nodejs.org/) لتشغيل متصفح Playwright الذي يقرأ به الكشّاف المواقع.
- [Git](https://git-scm.com/downloads) لتنزيل المشروع.

## التشغيل لأول مرة

1. نزّل المشروع وادخل مجلده:
   ```bash
   git clone https://github.com/Intisar3/accord-watch.git
   cd accord-watch
   ```
2. ثبّت مكتبات Python:
   ```bash
   pip install -r requirements.txt
   ```
3. (اختياري) عدّل `config.yaml`: الميزانية (`budget`)، والمناطق المفضلة (`location`)، وأقدم سنة (`min_year`)، وأوزان الترتيب (`weights`).
4. افتح المجلد في Claude Code وشغّل أول دورة:
   ```bash
   claude
   ```
   ثم اكتب:
   ```
   /daily-run
   ```
   أول مرة يسألك Claude Code إن كنت تثق بالمجلد، وإن كنت توافق على أداة المتصفح `playwright` المعرّفة في `.mcp.json`. وافق على الاثنين.

   أول دورة تأخذ وقتًا أطول (30 إلى 60 دقيقة) لأن كل الإعلانات جديدة. من اليوم الثاني يُعاد التدقيق فقط على الإعلانات التي تغيّر نصها أو صورها، وتغيّر السعر وحده يعيد التسعير والترتيب فقط.
5. افتح `reports/latest.html` في المتصفح. كل يوم تُحفظ نسخة باسم التاريخ في نفس المجلد.

كل شخص يشغّل المشروع على جهازه وباشتراكه، وقاعدة البيانات (`data/`) والتقارير (`reports/`) تبقى عنده ولا تُرفع إلى GitHub.

## الجدولة اليومية

**Windows:** شغّل `setup.ps1` مرة واحدة، فهو يثبّت المتطلبات وينشئ مهمة يومية الساعة 7:00 صباحًا. أو أنشئ مهمة يومية بنفسك في Task Scheduler (مثلًا 7:00 صباحًا) تشغّل:
```
powershell -ExecutionPolicy Bypass -File "C:\path\to\accord-watch\run_daily.ps1"
```

**macOS / Linux (cron):**
```
0 7 * * * /path/to/accord-watch/run_daily.sh
```
السجلات تُحفظ في مجلد `logs`.

ملاحظة لـ macOS وLinux: الأوامر مكتوبة باسم `python`. إذا كان Python عندك باسم `python3` فقط، أنشئ اسمًا بديلًا (alias) أو ثبّت حزمة `python-is-python3`.

## كيف يُحسب الترتيب

الدرجة من 100، والأوزان قابلة للتعديل في `config.yaml`:
- الميزانية 25: كاملة حتى 4,500 ريال، وتنزل تدريجيًا حتى 5,500.
- الحالة 25: من تقييم الحَكَم.
- التطابق 20: كل تعارض خطير ينقص 30 وكل تنبيه ينقص 10.
- قيمة السعر 15: مقارنة بمتوسط سيارات مشابهة.
- العمر والممشى 10.
- الموقع 5: مسقط أولًا.

السيارة التي فيها تعارضان خطيران أو أكثر تنزل درجتها 40%.

## أدوات للاستخدام اليدوي

```bash
python tools/db.py ranking                 # الترتيب الحالي
python tools/db.py show opensooq:123456    # كل ما يُعرف عن إعلان
python tools/db.py market --year 2018      # أسعار السوق لسنة معينة
```

## حدود يجب معرفتها

- الفحص البصري يشير إلى ما يستحق السؤال، والقرار النهائي بعد فحص فني في ورشة أو وكالة وتقرير تاريخ السيارة.
- الوكلاء يقرؤون الصفحات العامة فقط، مرة واحدة يوميًا وبهدوء، بدون تسجيل دخول أو تواصل مع البائعين. راجع شروط كل موقع قبل التشغيل المنتظم.
- الوكلاء على نموذج opus يستهلكون حصة أكبر. لتقليل الاستهلاك غيّر `model` في ملف الوكيل إلى `sonnet`.
